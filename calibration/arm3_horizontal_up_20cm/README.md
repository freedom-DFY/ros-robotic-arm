# 固定起点后执行的 20 cm 水平直线

现在采用固定流程：**使能保持当前位置 → 调用 `/arm3/run_fixed_line` → 关节空间低速回到固定起点 `[3923,1061,2105]` → 到位稳定 → 走固定 20 cm 直线 → 到终点稳定**。参考零位仍是 `[3819,989,2013]`；固定起点是一次运动的目标，不会重置零位。

归位段不受测试用软件窗口或笛卡尔逆解限制：三个轴从各自实际编码值，按同一进度插值到固定起点，最大关节速度 0.02 rad/s。允许起始编码在软件测试窗口外，但须在文档对应的机械运行边界内；归位时末端路径可以弯曲。归位的起点、目标和流式指令受独立 `mechanical_*` 参数及舵机内部位置范围限制，并保留通信、跟踪、停止和超时处理。机械反馈边界全程生效，后续 20 cm 直线仍在开始流程前完整预检查软件限位、逆解与分支连续性；第一段到位稳定后，软件测试窗口的反馈检查重新启用。

使能阶段只读取并保持实际位置，已取消软件工作空间和校准标记对初始使能的限制。即使当前位置在软件窗口外，也能先使能保持，并在配置已确认后执行上述关节空间归位。型号、通信、位置模式及舵机内部寄存器限制检查保留。

若使能返回 `Motor ... did not accept the hold position`，表示保持目标写入后的寄存器读回未通过核对，尚未进入本次使能的上扭矩阶段。程序最多读回复核 3 次，间隔 10 ms；持续不一致时会报告 `requested`、`goal_readbacks`、当前编码、扭矩状态、模式、硬件错误和 Bus Watchdog 值。保留完整响应以定位问题，先处理此错误，再执行运动服务。更新程序后需重启控制节点才会使用新代码。

到位判据为每轴距目标不超过 **10 刻度（约 0.88°）**，并在 **0.5 秒**稳定期内相对稳定期起始读数变化不超过 3 刻度。该判据允许实际舵机跟踪误差，不承诺编码反馈完全相同。若未到位或任一阶段超过 120 秒，流程会故障停止，第二段不会因等待超时而自动启动。

`/arm3/run_fixed_line` 返回成功仅表示接受流程。`/arm3/motion_status` 会发布 `moving_to_start`、`settling_start`、`line_motion`、`settling_end`、`completed`；`/arm3/stop`、关闭使能或通信/跟踪故障会取消整个流程，之后不会自动续跑。运行期间其他目标和重复启动被拒绝，需先停止。
