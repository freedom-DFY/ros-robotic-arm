# 硬件参数与标定依据

当前程序为六个旋转关节加一个独立夹爪电机。前三轴沿用原实机测量记录，
后三轴已按接线记录填写 ID；其标定、腕部几何与夹爪参数仍待实测。

## 前三轴保留值

| 参数 | J1 / ID1 | J2 / ID2 | J3 / ID3 |
| --- | --- | --- | --- |
| 型号 | XM540-W270 | XM540-W270 | XM540-W270 |
| 零位 tick | 3819 | 989 | 2013 |
| 编码方向 | +1 | -1 | -1 |
| 运行下限 tick | 0 | 740 | 1047 |
| 运行上限 tick | 4095 | 2700 | 3347 |
| 速度上限 rad/s | 0.02 | 0.02 | 0.02 |

大臂和小臂长度按 2026-11-27 提供的尺寸更新为各 170 mm（0.170 m）。
基座高度仍为 0 m；前三轴标准 DH 偏置为 `[0,0,π/2]`。
编码映射为 `q=direction*(tick-zero)*2π/4096`。

限位依据：2026-11-13 根据原始《关节角度限制》记录整理。
ID1 没有记录机械挡块，当前仍为 Mode 3 单圈 0–4095，不采用跨零点或连续旋转逻辑。
ID2 原记录 740–3323，建议不超过 2700；小臂完全收缩时上限 2809，因此统一采用 2700。
ID3 按记录采用 1047–3347。编码增大与运动学角度增大的方向不必相同，不因“上抬”描述修改符号。

对应当前配置为 `src/arm6_ros2/config/arm6.yaml`；前三轴位置公式的一致性由
`test/test_arm6_model.py` 检查。历史三轴轨迹文件已删除，标定数值及依据保留在此。

## 暂定新增硬件

J4–J6 按关节顺序使用 ID5、ID4、ID11，型号填写 XH430-W350（1000）。
其中 ID4 的型号来自已有 Wizard 记录；ID5、ID11 和夹爪的型号需在扫描时一起核对。
夹爪 ID 尚未实测，配置末项 ID7 仅为占位值，需用 Wizard 以 1 Mbps 单独扫描后替换。

后三轴零位 2048、方向 +1、运行限位 1024–3072 均为占位标定；
相交球腕和法兰至 TCP 沿局部 Z 轴 0.12 m 仍为几何假设。
夹爪闭合/张开 1800/2600 tick、完整开口 0.06 m 也待标定。
实测后填写轴线、安装变换、零位、方向、限位和工具参数，再打开对应的 confirmed 开关。
